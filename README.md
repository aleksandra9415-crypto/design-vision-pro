# Design Vision Pro

Промпт для Lovable — v1 (MVP-каркас, без брендинга и без реальной ИИ-генерации)

Что создаём

Веб-сервис дизайна интерьера, ландшафта, фасада и визуализации по схеме мебели с помощью ИИ (структурный ориентир — intora-design.ru, но шире: три вертикали плюс отдельный раздел для профессиональных дизайнеров). Это ПЕРВАЯ версия — нужен полностью рабочий, кликабельный каркас с реалистичным содержимым, но БЕЗ настоящей интеграции с ИИ (бэкенд ещё не готов): везде, где должна происходить генерация, используй правдоподобные mock-данные и имитацию загрузки (2-3 секунды), а не реальные вызовы API.

Страницы

Главная (/)

Хедер: текстовый лого-плейсхолдер, навигация на 3 мини-лендинга, кнопка «Войти»

Hero: заголовок и подзаголовок про дизайн интерьера по фото или по схеме мебели, CTA-кнопки

Блок «Как это работает» — 4 шага: загрузка фото → выбор стиля → генерация ИИ (~60 сек) → результат с сравнением до/после

Галерея примеров — карточки «стиль + тип помещения» с фото до/после (плейсхолдер-изображения)

3 карточки-перехода на мини-лендинги: Интерьер / Ландшафт и фасад / Для профи

Отзывы — 3 карточки (имя, город, короткий текст)

Футер со ссылками на все публичные и юридические страницы

/interior — Дизайн интерьера по фото (для частников)

Свой hero под эту аудиторию, галерея стилей (сканди, лофт, минимализм, классика, джапанди, хюгге и т.п.), CTA на генератор с deep-link на вкладку «интерьер»

/exterior — Дизайн ландшафта и фасада

Та же структура, но про экстерьер дома и участка; CTA на генератор с deep-link на вкладку «экстерьер»

/pro — Для дизайнеров интерьеров

Позиционирование: генерация по схеме расстановки мебели, коммерческая лицензия включена в любой платный пакет; CTA на генератор с deep-link на вкладку «чертёж»

/pricing — Тарифы

Разовые пакеты кредитов, 3 тарифа (старт / оптимум / максимум) с количеством генераций и ценой; отдельный блок о коммерческой лицензии для про-аудитории (включена в любой платный пакет, не отдельная подписка)

/faq — Вопрос-ответ

Аккордеон, 5-8 вопросов (бесплатные генерации, нужна ли карта, сохраняется ли структура помещения и т.п.)

/auth — Вход / регистрация

Простая форма email + пароль, переключатель вход/регистрация, кнопка входа через Google как заглушка

/app/generator — Генератор (после входа)

Вкладки сверху: Интерьер (по умолчанию) / Экстерьер / Чертёж

Форма: загрузка фото (drag-and-drop), тип помещения, стиль (карточки), необязательное поле «уточнения», кнопка «Сгенерировать»

После отправки — экран ожидания (mock, 2-3 сек) → результат

/app/result — Результат

Сравнение до/после (слайдер), кнопка «Скачать», кнопка «Сгенерировать ещё», список использованных параметров

/app/account — Личный кабинет

Баланс кредитов, история генераций (карточки с миниатюрами), кнопка «Пополнить»

/app/billing — Оплата

Выбор пакета (переиспользовать карточки с /pricing), форма оплаты как заглушка, без реальной платёжной интеграции

Юридические страницы

/terms, /privacy, /offer, /payment-info — простые текстовые страницы-заглушки с заголовками

Общие технические указания

Все данные (стили, примеры, отзывы, тарифы, история генераций) — реалистичные mock-данные, не реальные API-вызовы

Генерация — имитация: после отправки формы показывай загрузку 2-3 секунды, затем возвращай заранее подготовленное изображение «после» (можно переиспользовать один и тот же небольшой набор плейсхолдер-фото для разных стилей)

Переход с любого мини-лендинга на генератор должен сразу открывать нужную вкладку (интерьер/экстерьер/чертёж), а не всегда дефолтную

Обязательна мобильная адаптивная вёрстка

Оформление — чистая, светлая, современная SaaS-эстетика, нейтральный акцентный цвет. Это ВРЕМЕННОЕ оформление: точный брендинг (логотип, палитра, шрифты) подключим отдельным шагом позже, сейчас не старайся угадать финальный стиль

Иконки — стандартная библиотека (lucide и подобные)

Чего пока НЕ делаем в этой версии

Реальную интеграцию с ИИ-генерацией изображений

Реальный платёжный шлюз

Командные/мультипользовательские функции (роли, приглашения)
